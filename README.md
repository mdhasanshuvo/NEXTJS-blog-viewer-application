# Next.js Blog Viewer Application  

A simple blog viewer application built with Next.js to demonstrate routing, dynamic routes, authentication, and data fetching.  

## Features  
- **Home Page**: Displays a list of blog posts fetched from a mock API.  
- **Blog Details Page**: Dynamically fetches and displays detailed information for each blog post.  
- **Protected Profile Page**: Accessible only to authenticated users using Kinde Auth.  
- **Navigation**: Includes links to Home and Profile, with conditional Login/Logout buttons.  
- **Responsive Design**: Styled using Tailwind CSS for a clean and user-friendly interface.
